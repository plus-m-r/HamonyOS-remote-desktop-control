## 8️⃣  为什么不能直接复用Java源代码?

❌ UI层
  Java: Swing 桌面框架
  Flutter: Material Design 移动框架
  → 完全不同的框架,无法复用

❌ JNI层
  Java: JVM本地库调用
  Flutter: Dart运行时
  → 系统级差异

❌ 网络层
  Java: Netty框架
  Flutter: Dio + WebSocket
  → 库架构不同

✅ 但通过协议和数据结构复用,实现了最大的兼容性!

## 9️⃣  实际代码复用示例

### 鼠标点击流程

Java方式:
  CmdMouseControl press = new CmdMouseControl(500, 300,
      CmdMouseControl.ButtonState.PRESSED,
      CmdMouseControl.BUTTON1);
  controller.fireCmd(press);

Flutter方式 (复用Java协议):
  MouseEvent event = MouseEvent(
    x: 500, y: 300, 
    button: 'left', 
    action: 'down'
  );
  await service.sendMouseEvent(event.toJavaProtocol());
  // 发送: {x: 500, y: 300, info: 5, rotations: 0}

✅ 数据完全兼容!

### 屏幕更新流程

Java方式:
  RobotCaptureResponse response = new RobotCaptureResponse(
      screenBytes, frameId);

Flutter方式 (复用Java格式):
  FrameData frame = FrameData.fromJavaResponse(
    {'screenBytes': data, 'id': frameId},
    width, height
  );

✅ 格式完全兼容!
